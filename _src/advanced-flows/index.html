You already know the tools. Flows is where you stop running them one at a time.

Everything from Module 03, reorganised into the order you'd actually build in: understand why the canvas exists, learn what a node is and how two run modes handle the sequencing, chain image → video → audio, pick up the supporting tools that remove the usual stalls, then let MagicFlow lay the whole thing down for you — end to end, in the time it takes to make coffee.

The big idea

A flow is not a shortcut for making one video — it's a machine you build once and run again. Connect an image node into a video node and that image becomes the start frame automatically; connect it into a storyboard node instead and one image becomes an entire scene's worth of continuation shots. No downloading, re-uploading, or losing track of which file was which. Build the chain by hand when you know exactly what you want, or describe the concept to MagicFlow and let it lay down the whole canvas — nodes, prompts, and running order — for you to approve shot by shot before a single credit is spent on video. Either way the destination is the same: press Run Flow once and walk away with a finished ad.

01

Why flows exists — multiplication, not replacement

Lesson 1 · 1m 43s

Everything before this module taught the individual parts of AI creation: tools, models, prompts, images, video, consistency, motion, the thinking that has to happen before you generate anything at all. Flows is where those parts start connecting to each other instead of living as separate, disconnected steps.

Flows is PromptWise's node-based creation system — a visual canvas where each AI step becomes a block, and blocks connect to each other with lines. Instead of generating an image, downloading it, and re-uploading it into a video tool, you draw one connection and the output moves forward on its own. Build the chain once; the system runs the steps in the correct order every time after that.

Flows doesn't change what makes a good generation — only what happens after it. The prompt framework you already use still matters here exactly as much as it did before: subject, environment, camera, lighting, mood, style, motion, consistency. Nodes are the same core tools as PromptWise's Studio, not a simplified version of them. What changes is that a strong image doesn't dead-end at "download" anymore — it becomes the input to the next step automatically.
02

The canvas — nodes, connections, and two ways to run them

Lesson 2 · 7m 08s

Think of the canvas as a big creative whiteboard. Every block you place on it is a node, and every node does exactly one job — generate an image, generate a video, hold a gallery, store a prompt. You place nodes by clicking them in the sidebar or dragging them onto the canvas, drop images or video straight in from your desktop (leave them as loose visual reference, or hit convert to turn them into a working node), and draw a connection by dragging from one node's corner to another. Whatever a node produces becomes available to whatever it's connected to — dynamically, so if you regenerate the upstream node, the change propagates forward.

Basic canvas mechanics: scroll to zoom, click-drag the background to pan, the centre button snaps you back to the middle when you lose your place, clear wipes the whole canvas, and Shift-click selects several nodes to drag as a group. Resize a node from its bottom-left handle; delete one with the delete button; click a connector line (or its X on hover) to remove just that link.

Run Node vs. Run Flow

Test one step

Run Node

Executes a single node in isolation. Use this while you're still deciding whether an image is strong enough to commit to animating — check the result before anything downstream fires.

Execute the chain

Run Flow

Runs every connected node in dependency order. If a video node needs an image that doesn't exist yet, Flows generates the image first, waits for it to finish, then feeds it forward and runs the video node — you never have to sequence it manually.

A rerun selection redoes every node currently on the canvas; a stop button cancels a flow mid-run. Cost is calculated automatically from whichever models and settings are attached to each node. And once a chain works, it isn't a one-off — save it and reuse it as a template, swapping individual steps for the next piece of content instead of starting from a blank canvas every time.

03

Image nodes — still the foundation of everything else

Lesson 3 · 5m 46s

The image generator is the node everything else in a flow tends to hang off, for the same reason it mattered before Flows existed: images are cheaper, faster and easier to control than video, and a bad image produces a bad video every time. If the character looks fake at the still-image stage, motion only makes it more obvious. The node itself holds nothing new — prompt, model, aspect ratio, quality, the wise enhanced prompt option — but what you can attach to it and do with its output afterward is where the leverage is.

Two ways to add references

Upload manually from your desktop when you already have a product photo, a character shot, or a mood board to follow. Or — the faster way — connect an already-completed image node straight into a new one: generate a character in one node, a product in another, connect both into a third, and ask that third node for an image of the character holding the product. Up to eight image references can feed a single image generator node at once, each shown as a thumbnail so you can see exactly what's feeding what. This is the mechanism behind consistent AI-influencer content, product ads, and any brand visual that needs the same subject to reappear.

The carousel

Running an image node a second time doesn't overwrite the first result — it appends a new one into a carousel you flick between. That matters because AI generation is rarely perfect on attempt one: the first pass might be decent, the second has better lighting, the third has a better pose. Instead of losing track of versions across separate downloads, they stay attached to the node, and whichever one is selected in the carousel is the one that flows downstream to whatever's connected next.

Quick actions, once an image exists

Bring it to life

Animate

Spawns a connected video generator node with the image already loaded as the start frame — the fastest path from a still you like to motion.

Isolate the subject

Remove Background

Spins up a connected Remove Background node against the image, no manual wiring needed.

Explore nearby

Variations

Keeps the general concept and idea but changes surface details — pose, outfit, colour — when a result is close but not quite right. A gallery spawns to hold the batch.

Cover more ground

Angles

Generates the same subject from a wider set of camera angles — the tool for campaigns, product shoots, and anything needing several consistent shots of one setup rather than one perfect one.

Change what exists

Edit vs. Rerun

Edit repopulates the image into the reference box so you can type a targeted change ("make the ice cream pink") to the same image. Rerun is a full redo — it regenerates from the original prompt and references from scratch, rather than editing the current result.

Image nodes can also be lined up in sequence on the canvas purely as a visual planning tool — arranging them shot by shot turns the canvas itself into a storyboard before a single video node has run.

04

Video and audio nodes — the same models, wired instead of copy-pasted

Lesson 4 · 2m 07s

Video generator nodes carry the same settings as their Studio counterparts — text-to-video, start/end frames, omni-reference on models that support it. What changes is how they get fed: connect an image node into a video node and that image snaps into the start-frame slot automatically. Add a second connected image and it becomes the end frame. Delete either image and the connection breaks with it — the video node simply reverts to whatever's left attached.

Omni-reference models such as Seedance accept up to nine connected references inside the node, each populating as a thumbnail exactly like the image node's reference bank. Multi-shot toggles (Kling) work the same way here as in Studio — toggle it on and add shots directly on the node.

Generate Prompt for Me. Connect an image and you don't have to write the motion prompt yourself — this button analyses the frame and returns a prompt suited to that specific scene. It's one more place the module removes a step that used to require a decision.

Audio nodes generate ElevenLabs voices, sound effects and music, and pair well with free sources like Pixabay for extra layering. Audio behaves differently from the image → video chain: most of the time it's created on its own and dropped into the final edit rather than wired directly into a video node. The exception is omni-reference models — toggle omni reference on and an audio slot appears, so connecting an audio node sends the sound in as a reference the video generation actually reacts to.

05

The rest of the toolkit — small nodes that save the real time

Lesson 5 · 7m 16s

Image, video and audio nodes are the core of most flows, but the smaller tools around them are what stop a canvas from turning into repetitive, disorganised busywork once it grows past a handful of nodes.

Prompt node — one script, many generatorstext only

Use when the same idea needs testing across several models, or you just want one place to store and reuse copy instead of retyping it.

write once → connect to node 1, node 2, node 3 → edit the prompt node → every connection updates

The propagation is one-directional: the prompt node is the source of truth, but you can still hand-edit the copy inside any individual connected node without it flowing back upstream.

Upscale node — resolution before it matters2× / 4×

Use before a hero image goes to a client, a website, or into a video node that needs more detail to animate.

1K source → 2× (2K) or 4× (4K)

Easy step to skip, but the extra resolution feeding a video model shows up as a genuinely clearer motion result, not just a sharper still.

Remove Background nodecutout

Product shots, thumbnails, stickers — anywhere the subject needs to sit on a different background than the one it generated against.

connect image → run → transparent cutout

Small and simple, but constantly reached for once you're assembling layouts rather than single images.

Storyboard node — the one that answers "what's the next shot"continuation

The most common beginner stall: one strong image exists, and no idea what the other four shots of the ad should be. Storyboard exists specifically to remove that stall.

connect 1–2 reference images → set shot count, aspect ratio, quality → generate → gallery of continuation shots

It analyses the connected image and writes a run of prompts that carry the story forward while holding subject and style steady — a woman on a beach day starts reading, then orders a cocktail, then takes photos, without the visual language drifting between shots. Feed it two references at once (an influencer plus a product) and it builds the sequence around both together. This is not the same job as Angles: Angles reshoots the same moment from different cameras; Storyboard invents the next moments.

Image & video galleries — collection, not generationimage / video

Once a canvas passes a handful of nodes, loose outputs floating separately become impossible to track. Galleries hold a set in one place.

send outputs to gallery → compare, reopen, convert back to a node → (image galleries) Animate All

A gallery also works as a reference bank: connect one to an omni-reference slot, or to a start/end-frame pair, and a pop-up lets you pick which stored images feed that generation — no re-uploading. Animate All is the shortcut that turns storyboard → gallery → finished clips into a single action: run it and every image in the gallery gets sent to video generation at once.

06

MagicFlow — describe the concept, get the whole canvas back

Lesson 6 · 4m 46s

Everything so far assumes you're building node by node, which is powerful because you control every decision — but sometimes the idea exists before the plan does. You know you want a cinematic shoe commercial, or a coffee-brand story, or a sci-fi trailer, and that's genuinely all you know yet. MagicFlow, powered by wise, takes a short description and builds the entire flow for you: nodes placed, prompts written, connections made.

1
Describe the concept

Keep it short and directional rather than exhaustive — "a cinematic sports drink advert set in a hot desert, focused on energy, endurance and speed" is enough. You're pointing wise at a direction, not scripting every scene.

2
Choose scene count

More scenes means a more complete piece, but also more generations and more credits spent before you've reviewed anything. Five scenes is plenty for a short ad or reel; go higher only for a longer cinematic sequence.

3
Set aspect ratio up front

9:16 for TikTok, Reels and Shorts; 16:9 for YouTube and widescreen ads. Deciding this after generation is the same wasted afternoon it always was.

4
Pick image quality and a default video model

Sets the baseline every generated node in the flow will inherit.

5
Attach references — optional but recommended

A product photo, a character reference, a style board. References let MagicFlow understand what you actually want instead of guessing from words alone.

6
Generate

The canvas populates with nodes already built. Image nodes start running immediately; video nodes arrive pre-loaded with motion prompts tailored to each image, but sit idle rather than firing on their own.

The video nodes don't auto-run, and that's deliberate. If one of the generated images isn't right, you simply never run its video — the setup is automated, but the judgement call on what's worth animating stays yours. From there the images become a starting point, not a finished set: run angles, storyboards or variations on any of them until they're actually ready.

The two demonstrated examples land the same point differently — a desert energy-drink ad built from two attached references, and a claymation soap advert where an animated character reference and a product reference produced ten consistent, on-style images from one short prompt, with no individual prompt written by hand. MagicFlow's job isn't to replace creative judgement; it's to remove the blank canvas as the first obstacle.

07

Shipping an ad in under 10 minutes — the full chain, worked

Lesson 7 · 6m 00s

The proof of everything above, run as one real brief: a face-oil advert commissioned by a skincare brand. The entire production — every node in this guide used in sequence — took about ten minutes of actual work, and the majority of that was reviewing outputs, not creating anything by hand.

1
Brief MagicFlow

Upload the avatar reference and the product photo, write one short prompt describing the ad, choose eight images.

2
Review the eight assets

Check avatar consistency, bottle rendering, and label text across every image before spending anything on video — exactly the checkpoint MagicFlow's non-auto-run design exists for.

3
Run all the video nodes

Motion prompts were already written by Generate Prompt for Me during setup — no manual prompting at this stage either.

4
Run Angles on the strongest still

A close-up bottle shot earned four more angle variations — extra coverage without a new generation from scratch.

5
Run Storyboard on a hero image

Continued the story on the woman shot, generating further consistent scenes to round out the set.

6
Animate All on the resulting gallery

Selected Kling and ran every storyboard image to video in one action — ten more finished clips, including a crane shot rising above the model's head that turned out to be one of the strongest in the set.

7
Generate music with an audio node

The last generative step — a soundtrack sized to the ad, produced alongside everything else rather than sourced separately.

8
Assemble in CapCut

Download every clip, drop them in, add transitions, tighten pacing by trimming some clips, reorder for a stronger flow, lay in the generated music. Ordinary edit craft — nothing here that a CapCut pass from earlier in the course didn't already cover.

The only prompt written by hand for the entire advert was the MagicFlow brief at the start. Everything after it — the per-shot motion prompts, the angle variations, the continuation storyboard, the batch animation — was generated, reviewed, and approved rather than typed. It can always be improved with more time: extra sound effects, finer pacing, more deliberate shot selection. But the baseline it replaces is a camera crew, a location, actors and a production budget, compressed into a workflow one person runs from a laptop.
